# 狼人杀 App（单文件前端）

这是我自己做的一个「AI 角色聊天」前端里的**狼人杀**模块：整个 App 只有**一个网页文件 `index.HTML`**，
不用安装、不用构建，用手机浏览器打开就能玩。
所有数据（角色、聊天记录、战绩）都存在**本机浏览器**里，不会上传云端。

## 怎么玩

1. 把 `index.HTML` 存到手机里（放在本仓库目录里就行）；
2. 用浏览器打开它 → 第一次进去要在「设置 → 接口」填一个 AI 接口（地址 / Key / 模型）；
3. 桌面 →「游戏」→「狼人杀」→ 开始。

游戏里：准备页右上角 **⚙** 是设置（玩法 / 人数 / 身份 / 选角色都在里面）；
牌桌会跟着阶段自动换背景（清晨 → 中午 → 黄昏 → 处刑台 → 午夜 → 房间）；
底部左边那个 **🏷** 是标记角色（怀疑狼、像预言家、给编号上色…）。

## 仓库里有什么

| 文件 | 说明 |
|---|---|
| `index.HTML` | 整个 App（HTML + CSS + JS 全在这一个文件里） |
| `lk-icon-flash.png`、`lk-icon-cam.png` | 锁屏那套图标（缺了锁屏会少两个图标） |
| `AGENTS.md` | 这个项目的开发约定（给 AI 助手看的说明） |
| `.gitignore` | 备份、截图、临时文件不上传 |

## 改完代码怎么更新到 GitHub

在手机 Termux 里进到本目录，跑这三条：

```bash
git add index.HTML
git commit -m "改了什么（一句话）"
git push
```

第一次 `git push` 会要你填 **GitHub 用户名**和一个 **token**（不是账号密码）。
